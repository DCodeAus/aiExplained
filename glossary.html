Glossary

Every jargon term from this guide (plus a few you'll meet in the wild), in plain English.

TermPlain-English meaning
AgentAn LLM running in a loop with access to tools, so it can take multiple steps and perform actions (search, run code, send messages) to complete a task. See Part 4.
AI (artificial intelligence)Umbrella term for computer systems doing things that normally need human intelligence. LLMs are one kind of AI.
Context windowThe maximum amount of text (in tokens) a model can consider at once - its working memory. See Part 3.
Fine-tuningAdditional training on a curated dataset to shape a model's behaviour - e.g. teaching a raw model to act like a helpful assistant. See Part 2.
Function calling / tool useThe mechanism letting a model request an action (like a web search); external software runs it and feeds the result back. See Part 4.
GPUGraphics processing unit - the specialised chips (originally for video games) that do the heavy maths of training and running models.
HallucinationWhen a model produces fluent, confident, incorrect output - invented facts, citations or details. See Part 3.
InferenceRunning a trained model to get answers (i.e. what happens when you chat with it), as opposed to training it.
LLM (large language model)A neural network trained on vast amounts of text to predict the next token; the technology behind ChatGPT, Claude, Gemini and similar.
MCP (Model Context Protocol)An open standard for connecting AI apps to tools and data sources - a universal plug socket. See Part 4.
MultimodalA model that handles more than text - e.g. it can also see images, or hear audio.
Neural networkThe mathematical structure models are built from - layers of simple calculations with adjustable weights, loosely inspired by brain neurons.
Open weights / open source modelA model whose trained parameters are published so anyone can download and run it, rather than accessing it only via a company's service.
Parameters / weightsThe billions of adjustable numbers inside a model that get tuned during training; they encode everything it has learnt. See Part 2.
Pre-trainingThe first, biggest training stage: next-token prediction over an enormous text corpus. See Part 2.
PromptThe text you give a model - your question, instructions, and any material you paste in. See Part 3.
RAG (retrieval-augmented generation)Automatically finding relevant documents and giving them to the model alongside your question, so answers are grounded in real sources. See Part 4.
Reasoning modelA model trained to "think" through a problem at length (generating internal working) before giving its final answer; better at maths, logic and planning.
RLHFReinforcement learning from human feedback - polishing a model by training it to prefer answers humans rate highly. See Part 2.
System promptHidden instructions the app developer gives the model before your conversation starts ("You are a helpful assistant…"), shaping its behaviour.
TemperatureA setting controlling how adventurous the model's token choices are - low is predictable, high is creative/random. See Part 3.
TokenThe chunk of text (part-word, word, or punctuation) that models actually read and write. Roughly ¾ of a word in English. See Part 1.
TrainingThe process of adjusting a model's parameters using huge amounts of data until its predictions are good. See Part 2.
