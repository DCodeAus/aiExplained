The 60-second version

If you only read one paragraph on this whole site, make it this one:

A large language model (LLM) is a computer program that has read an enormous amount of text and learnt the patterns in it. Its one core skill is deceptively simple: given some text, predict what comes next. Everything impressive it does - answering questions, writing code, summarising documents - emerges from doing that one prediction, over and over, one small chunk (a "token") at a time. It doesn't look things up in a database, and it doesn't "know" facts the way you do. It generates likely text. That's why it's brilliant, and it's also why it sometimes confidently makes things up.

A few myths, busted up front

MythReality
"AI searches the internet for answers." By default, an LLM generates answers from patterns it learnt during training. Some tools add web search on top, but the model itself isn't searching anything.
"AI understands what it's saying." Debatable - and hotly debated! What's certain is it works very differently from human understanding. It has no lived experience, no senses, and no memory between conversations (unless memory is added as a feature).
"If AI says it, it must be true." LLMs can produce confident, fluent, completely wrong answers. This is called hallucination, and it's covered in Part 3.
"AI is one thing." "AI" is a huge umbrella. This guide covers language models - the tech behind chatbots. Image generators, self-driving cars, and recommendation systems are different (though related) technologies.
